# HiFi 交易事件簿

面向贴吧 HiFi 社区的静态交易事件展示网站，包含移动优先的公开页面和纯浏览器运行的维护者内容编辑器。项目不含后端、数据库、账号系统或自动投稿发布能力，适合部署到 GitHub Pages 的项目子路径。

## 当前状态

- `data/events.json` 已收录用户提供的四页 DOCX 名单，共 43 条文字记录。原文件没有截图或超链接，页面明确标注单方陈述与材料待补。
- 贴吧个人主页与官方水楼具体帖子链接已配置在 `data/events.json`，首页和详情页共用同一配置。
- 提供的原始 DOCX 没有复制进项目。公开数据中排除的敏感信息及改写范围见 `docs/DOCX_IMPORT.md`。
- 首页直接显示事件列表，青绿色耳机图片缩为角标，插画移至列表下方；浅色和深色模式均保留。

## 本地预览

Windows 用户可直接双击项目根目录的 **`启动并编辑网站.cmd`**。启动时可输入端口，直接按回车使用默认的 `4173`；如果上一次由本项目启动的预览进程仍在运行，启动器会先回收它，再启动新的进程。其他程序占用端口时，按提示换一个即可。启动器会打开可视化编辑器；编辑器右上角可进入网站预览。编辑期间保留启动窗口，完成后在窗口按回车停止本地预览。无需输入命令或手动编辑 JSON。

浏览器草稿按网址保存。换端口后，原端口下保存的草稿不会自动出现；请先在原端口导出备份，或在新端口导入已导出的 `events.json`。项目里的已发布数据仍会照常读取。

若要手动启动，也可以在项目根目录运行：

```powershell
python -m http.server 4173
```

然后访问：

- 展示站：`http://localhost:4173/`
- 维护者编辑器：`http://localhost:4173/editor/`

不能直接双击 HTML 文件运行，因为浏览器通常会阻止页面读取 `data/events.json`。

首页的搜索框支持账号、设备、标题、摘要和经过关键词；搜索会写入网址中的 `?q=`，可以复制筛选结果链接。搜索只在浏览器本地运行，不向外发送内容。

首页和详情页的投稿入口会先打开精简表格。投稿者填写经过、账号、平台、设备、日期、材料说明和可选的“投稿者的心情”，点击提交后网站先复制整理好的文字，再跳转到贴吧主页或水楼。复制失败时不会跳转，会在表单中显示可手动复制的内容。

## 项目目录

- `index.html`：事件卡片列表
- `event.html?id=事件标识`：可直接访问和刷新的事件详情固定网址
- `editor/index.html`：本地可视化内容编辑器
- 编辑器支持离线选择 DOCX、TXT、Markdown，读取原文并按段落生成待审阅草稿；原文不会自动进入正式网站。
- `data/events.json`：网站与编辑器共用的数据
- `assets/images/events/`：正式事件图片的目标目录
- `assets/images/examples/`：仅用于虚构演示的资源
- `docs/UPDATING.md`：维护与 GitHub Pages 发布说明
- `docs/GITHUB_PAGES_LLM_GUIDE.md`：交给其他 LLM 使用的上传与发布教程

## 检查

```powershell
npm run check
```

这个检查会验证 JSON、稳定标识、JavaScript 语法和图片相对路径，但不会代替实际页面运行与浏览器检查。
